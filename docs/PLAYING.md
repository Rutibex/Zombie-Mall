# Playing Zombie Mall

## Getting started

For the portable Windows release, **extract everything** from the Windows x64 ZIP, then run `ZombieMall.exe`. From the title screen choose **START ZOMBIE MALL**. Select all survivors with **G** and explore using mouse clicks. Click a discovered object or passage to move towards it; click again when close enough if necessary.

The opening expedition begins near the mall entrance, with access to the back-office refuge. Interactions and campaign submenus appear in side panels and contextual menus. Opening the journal, area map and help screen is recommended before your first expedition.

## Basic controls

| Input | Effect |
| --- | --- |
| Left-click world or object | Move, attack or interact (context-dependent) |
| Right-click | Context menu / cancel / inspect |
| `G` | Select all party members |
| `1`–`6` | Select a party member |
| Shift / Ctrl + click | Multi-select / toggle selection |
| `Space` | Pause or resume exploration |
| `Enter` | End current combat turn |
| `M`, `J`, `I` | Area map, journal, inventory |
| `F5`, `F9` | Quick save, quick load |
| `F1`, `Esc` | Help, back/menu |
| Arrow keys / middle-mouse drag | Move camera |
| Mouse wheel | Zoom |
| Hold `Tab` | Highlight discovered interactables |
| `Ctrl+M` | Mute |

The interface provides other actions, including class abilities, equipment, crafting, shelter, factions, and **MYSTERIES / FINAL ESCAPE**. Key bindings can be changed in options; in-game prompts are authoritative.

## Surviving the mall

Your party can explore separate areas connected by actual entrances and exits. Track the journal and objective board, inspect furniture and containers, keep enough food and water, and return finds to the refuge. Encounters are handled in turn-based combat; sound, alertness and horde threats affect expeditions. Workshop interactions support repair, crafting, salvaging and trades using owned resources.

To work towards campaign endings, examine **MYSTERIES / FINAL ESCAPE**. Actions require being beside the appropriate physical board or console. The refuge manages long-term planning; the helicopter and emergency consoles are on the roof. Save before major one-way decisions.

## Save files and updates

On Windows your local saves/preferences are stored under `%LOCALAPPDATA%\ZombieMall`, **not** inside the game folder. Save games embed the campaign data from the version in which they were created. A compatible older save can be continued, but it will not silently acquire all newly added map areas or finale content. For the full authored campaign, start a new game if coming from an older campaign release. The 0.33.2 environment-art pass itself needs no reset.
