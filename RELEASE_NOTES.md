# Zombie Mall v0.33.2 — Lower Mall Environments

**Zombie Mall** is a single-player party-based zombie survival RPG for Windows x64, created by Michael Robinson.

### Highlights

- A **170-area playable campaign** spanning 108 mall shops, 25 roof areas, 26 outside areas, and the refuge and connecting routes.
- Six survivor classes; tactical combat, scavenging, crafting, survival, shelter management, factions, evidence and multiple escape routes.
- Version **0.33.2** adds custom environmental graphics, fixtures and signage to **lower-mall shops 1–18**, plus updated connecting concourses.
- The latest art pass doesn't change the underlying save or campaign format; existing compatible saves can continue.

### How to install

Download the **Windows x64 ZIP release asset**, extract the entire contents to a folder, and run `ZombieMall.exe`. Keep `Assets/`, `Campaigns/` and `StylePacks/` next to it. This is a self-contained portable app, not an installer. A working OpenGL driver is required.

**When to start a new game:** to experience the expanded campaign and ending content, make a new campaign if your save predates those features. The 0.33.2 visual update alone does not require a restart.

### Current scope and notes
