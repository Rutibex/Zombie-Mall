# Zombie Mall — Windows x64 portable edition

**Version 0.33.2** · Created by Michael Robinson

This package is ready to play. Extract **all files and directories** to a normal folder, then double-click **`ZombieMall.exe`**. Select **START ZOMBIE MALL**.

The executable is a self-contained Windows x64 game. You do **not** need the .NET SDK. Keep the `Assets/`, `Campaigns/`, `StylePacks/` and `licenses/` directories next to the executable. Windows with a working OpenGL graphics driver is required.

Useful controls: left-click to move/interact, right-click for contextual options, **G** for whole-party selection, **Space** to pause exploration, **Enter** to end a combat turn, **M/J/I** for map/journal/inventory, **F5/F9** for quick save/load, and **F1** for help. Read `docs/PLAYING.md` for the full player guide.

The game includes **170 connected areas**, survivor classes, survival and shelter systems, crafting and combat, factions, mysteries and several ending routes. The latest version enhances the visuals of lower-mall stores 1–18; later art coverage remains in progress.

Saves live under `%LOCALAPPDATA%\ZombieMall`. Old saves keep their embedded campaign content; make a new campaign to experience the full latest map and endings if coming from a much earlier release. The current 0.33.2 environment update does not itself require a new save.

If you have launch trouble, see `docs/TROUBLESHOOTING.md`.
