# Security policy

Zombie Mall is a small single-player desktop project, not a continuously operated service. The game and source are provided without a promise of formal support or guaranteed security patch timelines.

**Do not post vulnerabilities, secrets, personal save data, or private local file paths in a public issue.** Use GitHub's private vulnerability reporting facility if it is enabled for this repository, or contact the repository maintainer privately using the contact method listed on the GitHub profile. Include a minimal proof of concept, impacted version or commit, and environment.

Avoid running modified binaries from untrusted parties. For source builds, audit dependencies and review the executable contents before distribution.
